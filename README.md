## 玩法（MVP）

守住中央的塔。敵人從四面八方湧入，塔會自動攻擊。

- **戰鬥內**：殺敵賺 **現金 $**，購買本場限定升級（攻擊/防禦/經濟三類）——死亡歸零
- **戰鬥後**：結算 **金幣 🪙**，回到工坊購買**永久**升級，下一場起點更強
- 每 10 波一隻頭目；敵人強度隨波次指數成長，總有一波會守不住——這是設計的一部分
- **主題戰區**：每 10 波切換戰區（翠綠曠野 → 寒冰荒原 → 熔岩裂谷 → 虛空深淵，循環），
  各區有獨立的敵人速度／血量／傷害／出怪量與獎勵倍率，越深入獎勵越高；
  場地以戰區主題色呈現雷達網格、能量信標與塔核心特效，HUD 同步顯示戰區名稱
- **卡片系統**：戰前配置卡片，**槽位有限**逼你取捨出流派。13 張分三類——
  數值卡（攻速/生命/範圍/爆擊/金幣）、規則卡（彈射/慢速靈氣/荊棘反傷/擊殺回血/利息）、
  條件卡（頭目剋星/策士/虛空掠奪者，與戰區、Perk 聯動）。里程碑解鎖、金幣升星（1~3★），
  不做抽卡；槽位可用金幣逐一解鎖（2→6）
- **研究室**：放置遊戲招牌機制。6 條研究線給永久屬性加成，用**真實時間**跑、**離線也在推進**，
  一次只能跑一項（開一項研究、回來收成）；隔天打開會結算離線期間完成的研究
- **終極武器**：戰鬥中主動施放的大招——黃金塔（限時金幣倍率）、黑洞（瞬間全屏傷害），
  各有冷卻與衝擊波/金光特效；達里程碑解鎖，用金幣升級威力與縮短冷卻
- **Perk 三選一（稀有度制）**：每 5 波三選一，分標準／稀有／史詩／傳說四級，**波數越深、越容易翻到高稀有度**；
  數值型 Perk 可**重複疊層**（池子不再越抽越爛），並可花場內現金**重骰**或**跳過領錢**。
  除了純數值，還有大量**觸發式 Perk**——處決者、精準節拍（每 4 發必爆）、破甲彈、腎上腺素、雙重射擊、
  殺意連鎖、冰霜新星、背水結界、賞金爆裂、巨獸殺手，以及傳說級的超載核心與殲滅協議（擊殺永久疊傷）
- **攻擊形態 Perk**：改變「開火方式」而非只加數字——**多重射擊**（同時打多名）、**穿透彈／軌道砲**
  （子彈貫穿一整排、每穿一名加成傷害）、**連鎖閃電／超導體**（暴擊電弧、對凍結敵人加倍）、
  **軌道衛星**（繞塔自動炮台，戰場上真的多一顆機體）。每條都是核心＋進階的小樹
- **元素流派**：Perk 可組成燃燒（疊層／爆擊強化／死亡傳染）與冰凍（冰霜疊層／脆化／碎冰）流派，
  進階 Perk 需先取得核心能力才會進入選池
- **免費升級機率**：工坊經濟線，買場內升級時有機率不扣現金（The Tower 招牌手感），命中會跳金光提示
- **戰區規則**：翠綠敵人會分裂、寒冰會侵蝕塔的攻速、熔岩週期性震傷雙方、虛空敵人會瞬移並在死亡時強化同伴；
  進入戰區時會顯示機制與應對提示，不再只是數值與顏色替換
- **戰術視覺系統**：全介面使用一致的 SVG 線框圖示；戰鬥 HUD、核心血條與流派指示重新分層，
  升級卡直接預覽購買後數值，Perk 顯示流派／稀有度／前置聯動，塔與戰場會依 Build 和戰區動態改變外觀
- **音效系統**：WebAudio 程式化合成，零音檔——開火/爆擊/擊殺/收金/頭目/大招各有音色，
  頂欄可一鍵靜音（記憶偏好）
- **三種新敵人**：分裂體（死亡分裂出小體）、吸血鬼（攻塔回血）、護盾兵（治療周圍同伴），
  波次依權重混入，逼你調整流派應對
- **Tier 難度階梯**：第 20 波解鎖下一 Tier，全域血量/傷害/獎勵倍增，各 Tier 獨立最高波紀錄，
  首次通關給大筆金幣——最省成本的長線內容
- **全球排行榜**：接 Cloudflare Worker + D1 後端，依「Tier 加權波數」排名，看得到別人打到哪
- **每日任務**：每日輪換三項任務（擊殺/波數/金幣/場次/終極），達標領金幣，跨日重置，頂欄紅點提示

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 產出 dist/（相對路徑，可直接丟任何靜態空間）
npm test         # 單元測試 + 平衡守門測試
```

## 專案結構

```
src/core/    純遊戲邏輯，不碰渲染、不碰瀏覽器 API（可獨立測試，未來可直接移植 Godot）
  sim.ts       固定 tick 戰鬥模擬（生成/移動/索敵/傷害）
  economy.ts   升級成本/效果公式、大數字格式化
  waves.ts     波次組成與敵人數值曲線
  stats.ts     屬性計算（基礎 + 工坊 + 場內）
src/data/    全部數值設定（JSON）——平衡是改表，不是改 code
src/meta/    存檔（含版本遷移）、工坊
src/ui/      Canvas 渲染
src/main.ts  畫面切換與主迴圈（固定 tick 模擬 + 每幀渲染，x1~x3 加速）
tests/       單元測試 + balance.test.ts（貪婪 AI 自動打整場，守住數值曲線目標）
```

## 平衡調整流程

1. 改 `src/data/upgrades.json` / `src/data/enemies.json`
2. `npm run balance` —— 貪婪 AI 模擬多場進度曲線，驗證：
   - 首場死亡波數 10~30、時長 3~15 分鐘
   - 連打 5 場後波數 ≥ 首場 1.3 倍（工坊成長有感）
